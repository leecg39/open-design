# Research Report Markdown Safety

## 관찰

- 저장 리포트는 외부 검색 결과의 `title`, `snippet`, 이미지 설명을 Markdown 문서 안에 직접 넣는다.
- 출처 URL은 HTTP/HTTPS로 정규화되지만, 출처 제목과 설명은 외부 텍스트다.
- 외부 텍스트에 줄바꿈, `##`, `[]`, `**` 같은 Markdown 문법이 포함되면 저장 리포트의 섹션 구조와 링크 표시를 흐릴 수 있다.

## 제품 리스크

- 리서치 리포트는 후속 의사결정과 A/B 비교의 근거 파일이다.
- 출처 텍스트가 새 헤더나 목록처럼 렌더링되면, 실제 리포트 작성자가 만든 구조와 외부 증거 필드가 구분되기 어렵다.
- 이미 "source content is external untrusted evidence"라는 주의 문구가 있지만, 문서 구조 자체가 흐려지면 사용자가 경고를 놓치기 쉽다.

## 개선 원칙

- 외부 출처에서 온 제목, 스니펫, 이미지 설명만 Markdown 제어 문자를 이스케이프한다.
- 요약과 메타데이터처럼 시스템이 만든 구조는 그대로 유지한다.
- 외부 텍스트의 줄바꿈은 공백으로 접어 하나의 목록 항목 안에 머물게 한다.
- 기존 정상 리포트 출력은 거의 바뀌지 않아야 한다.

## A/B 검증 기준

- Before: 출처 제목에 `## Fake Section` 또는 `[]`가 포함되면 리포트 구조나 링크 텍스트로 해석될 수 있다.
- After: 같은 텍스트가 `\#\# Fake Section`, `\[...\]`처럼 일반 텍스트로 남고, 리포트의 실제 섹션 구조는 유지된다.
