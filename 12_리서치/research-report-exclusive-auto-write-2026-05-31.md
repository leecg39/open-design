# Research Report Exclusive Auto Write

## 관찰

- `--save-report`는 기본 경로 충돌을 피하기 위해 다음 빈 `-2`, `-3` 경로를 찾는다.
- 현재 흐름은 빈 경로를 먼저 찾고, CLI에서 나중에 `writeFile`로 저장한다.
- 경로 확인과 쓰기 사이에 같은 파일이 생기면 자동 저장도 덮어쓰기 위험이 남는다.

## 제품 리스크

- Open Design에서 여러 agent/run이 같은 프로젝트와 쿼리로 리서치를 저장할 수 있다.
- 리서치 리포트는 A/B 검증과 근거 보존을 위한 산출물이므로 자동 저장은 경쟁 상황에서도 기존 파일을 덮어쓰지 않아야 한다.
- 앞선 overwrite protection은 일반 반복 실행에는 충분하지만, 동시 실행까지 막지는 못한다.

## 개선 원칙

- 자동 저장인 `--save-report`는 exclusive write (`wx`)로 파일을 생성한다.
- 파일이 이미 있으면 실패로 끝내지 않고 다음 suffixed path를 다시 시도한다.
- 명시 경로 `--report`는 사용자가 선택한 정확한 경로에 저장하는 기존 동작을 유지한다.

## A/B 검증 기준

- Before: 빈 경로 확인 후 쓰기 전에 파일이 생기면 자동 저장이 덮어쓸 수 있다.
- After: 자동 저장은 `wx`로 생성하고, 충돌 시 다음 경로를 선택해 기존 파일을 보존한다.
